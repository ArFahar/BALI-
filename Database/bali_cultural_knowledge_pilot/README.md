# Bali Cultural Knowledge Base — Pilot

This is a research pilot, not a fully locally validated production knowledge base.

Contents:
- `structured/cultural_knowledge.json`: combined JSON dataset
- `structured/knowledge_schema.json`: schema notes
- `structured/`: individual JSON records
- `processed/`: human-readable Markdown entries
- `metadata/source_registry.csv`: source inventory
- `metadata/verification_log.csv`: verification status
- `reports/`: research, source quality, and human review reports

Do not index all entries as fully verified. Preserve verification metadata and source URLs in RAG chunks.
